# CSVPP C++コード生成仕様書

**版:** 0.1（現行実装の解析版）  
**作成日:** 2026-10-11  
**対象:** `cpp_maker.xlsx`（`cmd`、`sample`、`usr_C`、`cpp_C`、`C++コード生成`〔表示上のシート名は環境により異なる可能性あり〕）、生成例 `sample.h`、`sample.cpp`

> 本書は添付ブックに記載された定義と生成例から読み取れる現行仕様を記録したものです。新機能案は末尾に分離しています。CSVPPエンジン自体の動作検証・生成再実行・C++コンパイルは行っていません。

## 1. 概要

CSVPPの表形式スクリプトを使い、`#class`、`#member`、`#method`、`#parm`、`#code` 等の入力から、C/C++のヘッダーファイルとソースファイルを生成する。`cpp_C` は生成ルール、`usr_C` は利用者独自のコマンド、`sample` は入力例、`cmd` は実行順序を記述する。

出力先の基本形は次のとおり。

```text
$output_dir$\$file_name$.h
$output_dir$\$file_name$.cpp
```

初期値は `output_dir = c:\csv`。`cmd` では `#file_def,sample` 相当の指定を行い、`sample.h` と `sample.cpp` を出力する構成になっている。

## 2. ワークブックの構成

| シート | 役割 | 主な内容 |
|---|---|---|
| `cmd` | 起動・制御 | `%include`、`%classcall`、`%set output_dir`、`#file_def`、`%output` |
| `sample` | 生成入力の例 | クラス、メンバー、メソッド、制御構文、コード片 |
| `usr_C` | ユーザー定義拡張 | `#CSV_LOOP` と `#LOOP_END` を定義 |
| `cpp_C` | 生成エンジン | コマンドの別名、入力解釈、断片蓄積、ファイル出力 |
| `C++コード生成` | 付属説明 | 概要・変数・コマンド一覧（ブック内の説明） |

**注意:** Excelの「使用範囲の最終行」と「実際に値が入った行数」は異なる。解析ではセル座標を優先している。

## 3. 実行の流れ

`cmd` シートの記述から読み取れる処理順序は以下のとおり。

1. `%include,cpp_C.csv` で生成エンジン定義を読み込む。
2. `%include,usr_C.csv` で利用者定義コマンドを読み込む。
3. `%classcall,usr_C,cpp` でクラスを呼び出す。
4. `%set,output_dir,c:\csv` で出力ディレクトリを指定する。
5. `#file_def,sample` で生成ファイルのベース名を指定する。
6. `%include,sample.csv` で生成元の入力を処理する。
7. `%output` で蓄積済みの内容を `.h` / `.cpp` に書き出す。

`cmd` に `%shell,text_create,...` の記述もある。これは別の処理を呼び出す箇所と読めるが、CSVPP実行環境の詳細は本資料だけでは確定できない。

## 4. 生成エンジンの内部構造

### 4.1 状態変数

| 変数 | 役割・初期値 |
|---|---|
| `file_name` | 出力ベース名 |
| `output_dir` | 出力先。初期値 `c:\csv` |
| `class_name` / `class_cnt` | クラス名の記録とクラス数（初期値 0） |
| `method_name` / `method_cnt` | クラス・アクセス区分ごとのメソッド管理 |
| `member_cnt` | クラス・アクセス区分ごとのメンバー数 |
| `pubKind` | アクセス区分。初期値 `public` |
| `parm_first_flg` | 引数リスト先頭かどうかの判定 |
| `g_comp` | 初期値 `<`（用途は要追加確認） |

### 4.2 出力断片の管理

`#write` / `#writeln` で名前付き断片に文字列を蓄積し、`#file` と `#key` で出力ファイルごとの結合順序を決める方式。

`.h` 側には `header_h`、`header_top`、`header_ext`、クラス宣言、アクセス別メンバー宣言、メソッド宣言、`header_end` 等を出力する。`.cpp` 側には `header_cpp`、`header_global`、メソッド定義・本体等を出力する。出力順は `cpp_C` シートの `output` 節（おおむね 73～231 行）に定義されている。

### 4.3 C言語モード

付属説明シートでは、`#class` のクラス名が `.` の場合、クラス宣言を出さない **C言語モード** と記載されている。`cpp_C` の `#method`、`#member` の分岐でも `class_name = .` を判定し、通常のC++クラスと異なる出力を行う。なお、ユーザーの現在の目的はC++生成機能の拡充である。

## 5. 入力コマンド仕様

以下は **ブックに実装・記載のある現行コマンド**。列はCSV化された表の隣接セルに相当する。正確な空欄の扱い・引数結合規則はコマンドごとに `cpp_C` を参照する。

### 5.1 ファイル・クラス・宣言

| コマンド | 主な引数 | 動作 |
|---|---|---|
| `#file_def` | ファイル名 | 出力ベース名を設定 |
| `#header_cpp` | 文字列 | `.cpp` の冒頭用断片に行を追加 |
| `#header_h` | 文字列 | `.h` の冒頭用断片に行を追加 |
| `#header_ext` | 文字列 | `.h` のクラス外定義に行を追加 |
| `#class` | クラス名 | 対象クラスを設定し、クラス宣言を構築 |
| `#kind` | `public` / `private` / `protected` | アクセス区分を指定 |
| `#public` / `#private` / `#protected` | なし | アクセス区分を切り替え |
| `#member` | 型、名前、コメント | メンバー変数を宣言 |
| `#method` | 戻り値型、メソッド名 | メソッド宣言・定義を開始 |
| `#parm` | 型、引数名 | 直前のメソッドに引数を追加 |
| `#local` | 型、名前、初期値 | ローカル変数を宣言 |
| `#global` | 型、名前、初期値 | グローバル変数を宣言 |

`#method` の戻り値型に `.` を使う例があり、コンストラクタ・デストラクタのように戻り値型を出さない用途で使われている。`#member` のコメントは `//` 形式で付与される。

### 5.2 本文とインデント

| コマンド | 主な引数 | 動作 |
|---|---|---|
| `#code` | 文字列 | メソッド本文に1行追加 |
| `#code0` | 文字列 | インデント0で1行出力 |
| `#code_sp` | 数値 | インデント幅を設定 |
| `#code_sp++` / `#code_sp--` | 増減量 | インデント幅を変更 |
| `###` | コメント文字列 | コメント出力用 |
| `#//` | コメント文字列 | コメント出力用 |

### 5.3 制御構文

| コマンド群 | 生成対象 |
|---|---|
| `#if` / `#elseif` / `#else` / `#endif` | `if` / `else if` / `else` ブロック |
| `#for` / `#endfor` | `for` ループ |
| `#while` / `#endwhile` | `while` ループ |
| `#do_while` / `#end_do_while` | `do ... while` ループ |
| `#switch` / `#endswitch` | `switch` 文 |
| `#case` / `#default` / `#endcase` | `case` / `default` と `break` の処理 |
| `#break` / `#continue` | `break;` / `continue;` |

`#endcase` は付属説明によると `non_break` 引数が空の場合に `break;` を生成する。

### 5.4 式・関数呼び出し

| コマンド | 概要 |
|---|---|
| `#printf` / `#fprintf` / `#sprintf` | 対応するC標準ライブラリ関数呼び出しを生成 |
| `#set` | 代入文を生成 |
| `#call` | 関数呼び出し文を生成 |
| `#set_call` | 関数呼び出し結果の代入を生成 |
| `#return` | `return` 文を生成 |
| `#delete` | `delete` 文を生成 |

### 5.5 利用者定義コマンド

`usr_C` には `#CSV_LOOP` と `#LOOP_END` が定義される。前者は `CSV_LOOP($p0$,$p1$,$p2$)` を出力してインデントを増やし、後者はインデントを戻して `LOOP_END` を出力する。C++標準構文ではなく、利用側のマクロ定義が必要。

## 6. サンプルから確認できる生成結果

`sample` シートには `text_cell_C` と `text_create_C` が登場する。添付の `sample.h` には両クラスの宣言、`sample.cpp` にはコンストラクタ、デストラクタ、`csvRead`、`wrRtn`、`fileRtn`、`keyRtn`、`output` などの定義がある。

例（`sample` シート）：

```text
#class,text_cell_C
#member,sChar,*key
#member,VariableArray_C,*ary
#method,.,text_cell_C
#parm,char,*p_key
#set_call,key,new sChar,p_key
```

生成コード例（抜粋）：

```cpp
class text_cell_C {
public:
    sChar *key;
    VariableArray_C *ary;
    text_cell_C(char *p_key);
    ~text_cell_C();
};
```

実際の出力は空白や改行が異なる。`sample.h` / `sample.cpp` の外部型（`sChar`、`MEM_FP`、`CsvAnl_C` 等）は本ブック単体では定義されないため、単独コンパイルできるサンプルではない。

## 7. 現状の制約・検証課題

### 7.1 添付された生成結果の注意点

- 添付 `sample.cpp` の `wrRtn(csvi,true)` にセミコロンがなく、C++として構文エラーとなる。ただし **今回の `sample` シート50行には `wrRtn(csvi,true);` とセミコロン付きで記載**されている。添付生成結果が修正前の版である可能性があり、再生成して比較する必要がある。
- 添付 `sample.cpp` には `int ii;` と初期化なしの宣言があるが、**今回の `sample` シート58行には `#local,int,ii,1` と初期値 `1` が指定**されている。これも再生成で確認する。
- `while(1)` の中の `switch(ii)` は `ii=5` に到達後も終了しない構造で、サンプル用途以外では無限ループになり得る。入力データ側の意図を確認する。
- `sample.h` には他の型の定義や `#include` がなく、コンパイルには周辺ライブラリが必要。
- `sample.h` の日本語コメントには文字コード由来と思われる文字化けが見える。入力・生成ファイルの文字コードを統一して確認する。

### 7.2 仕様の確認が必要な点

- 同名メソッドを複数定義したときの扱い（出力断片のキーにメソッド名を使う）。
- クラス切り替え時のアクセス区分の初期化と、宣言の並び順。
- `#header_cpp` / `#header_h` で指定した include と生成コードとの整合。
- `#method` における修飾子（`const`、`static`、`virtual`）や継承の扱いは、現行の明示的な専用コマンドとしては確認できない。
- `.xlsx` の内容をCSVPPへ渡す際のCSV化方法、文字コード、CSVPPバージョンおよび実行条件。

## 8. 改良案（**未実装・提案**）

既存のコマンド名を維持し、機能追加を段階的に行う。

| 優先 | 改良案 | 設計上の留意点 |
|---|---|---|
| 高 | `#include` 管理 | `.h` と `.cpp` を分け、重複排除を検討 |
| 高 | メソッド修飾子 | `const` / `static` / `virtual` と宣言・定義側の差を整理 |
| 高 | コンストラクタ初期化リスト | `#method` と本文の間に専用断片を追加 |
| 中 | クラス継承 | `#class` の引数拡張または新コマンド |
| 中 | namespace | ファイル全体の囲い込みと名前修飾の整合 |
| 中 | `enum` / `struct` | 既存クラス出力処理と独立した断片を追加 |
| 中 | 出力の検証 | サンプル再生成・差分・C++構文チェック |
| 低 | Doxygenコメント | コメントコマンドの追加 |

### 推奨する次の手順

1. 現行 `cpp_maker.xlsx` と添付生成例を保管する。
2. 現行ファイルから `sample.h` / `sample.cpp` を **再生成** し、差分を確認する。
3. セミコロン、初期値、文字コード、ループ終了条件を検証する。
4. まず `#include` 管理かメソッド修飾子のどちらか一機能を追加する。
5. 従来サンプルと拡張サンプルを回帰テストする。
