# CSVファイル→XMLファイル変換プログラム

## 1. ソフトの紹介

本プログラムは、CSVファイルをXMLファイルに変換するプログラムです。

2GB以上のデータにも対応しています。

## 2. 使用方法

本プログラムはコンソールプログラムです。

### 実行形式

```text
csvxml csv_file xml_file [-tag タグ設定ファイル] [-header ヘッダファイル] [-buff サイズ] [-e]
```

### オプション

- `-e`：エスケープコードへの変換を行いません。
- `-tag`：タグ設定ファイルを指定します。
- `-header`：ヘッダファイルを指定します。
- `-buff`：1回の読み書きに使用するバッファサイズを指定します（単位：KByte）。通常は指定する必要はありませんが、ファイルが大きい場合などには、大きな値を指定すると有効です。指定しない場合は10KByteとなります。

### 使用例

```text
csvxml data.csv data.xml
csvxml data.csv data.xml -tag tag.csv -header header.txt
```

## 3. タグ設定ファイル

タグ設定ファイルでは、全体を定義するタグ名、レコード単位のタグ名、項目のタグ名を指定します。

### 設定例

```text
#total_tag,DOC
#record_tag,REC
#tag,hinmei
#tag,tanka
#tag,suuryo
```

タグを指定しない場合は、以下のタグ名になります。

- 全体を定義するタグ名：`DOC`
- レコード単位のタグ名：`REC`
- 項目のタグ名：`TAG` + 番号

### (1) 全体を定義するタグ名の指定

#### 形式

```text
#total_tag,全体を定義するタグ名
```

#### 使用例

```text
#total_tag,DOC
```

### (2) レコード単位のタグ名の指定

#### 形式

```text
#record_tag,レコード単位のタグ名
```

#### 使用例

```text
#record_tag,REC
```

### (3) 項目のタグ名の指定

#### 形式

```text
#tag,項目のタグ名
```

#### 使用例

```text
#tag,suuryo
```

### (4) エスケープコード変換

XMLでは、以下の文字がエスケープコードに変換されます。

| 文字 | エスケープコード |
|---|---|
| `&`（アンパサンド） | `&amp;` |
| `>`（大なり記号） | `&gt;` |
| `<`（小なり記号） | `&lt;` |
| `"`（二重引用符） | `&quot;` |
| `'`（単一引用符） | `&apos;` |

`-e` オプションを指定すると、このエスケープコードへの変換を行いません。

## 4. ヘッダファイル

ヘッダファイルには、XMLファイルの1行目と2行目に記述する内容を指定します。

### 例

```xml
<?xml version="1.0" encoding="Shift_JIS"?>
<?xml:stylesheet type="text/xsl" href="aaa.xsl"?>
```

詳細については、XMLの規格を参照してください。
