# CSVファイルDIFFプログラム

## 1. ソフトの紹介

特定のデータ列のみを対象として、セル単位でデータのミスマッチチェックを行うプログラムです。

### チェック対象

例えば、以下のようなCSVファイルがあるとします。

```text
#key,900,200,300,300,44444444444444444

#ggg,200
#ggg,300

#gkkff,400,333333333333333333333

#key,200,300
#key,200,3012
#key,200,302
#gggg
#ddd
#key,200,303
#ffff
#key,200,3042
#ggg
```

この中で、**1カラム目のデータが `#key` の行だけ**をチェックします。

### 比較するファイル

以下の2つのファイルがあるとします。

#### `aaa.csv`

```text
#key,900,200,300,300,44444444444444444

#ggg,200
#ggg,300

#gkkff,400,333333333333333333333

#key,200,300
#key,200,3012
#key,200,302
#gggg
#ddd
#key,200,303
#ffff
#key,200,3042
#ggg
```

#### `bbb.csv`

```text
#key,900,200

#ggg,200
#ggg,300

#gkkff,400

#key,200,300
#fff,990

#key,200,301
#gggg

#key,200,302
#key,200,303
#key,[SKIP]

#key,200,304d
```

この2つのファイルを本プログラムでDIFFすると、以下のように出力されます。

```text
1   |#key,900,200,300,300,44444444 |x|1   |#key,900,200                  
2   |                              | |2   |                              
3   |#ggg,200                      | |3   |#ggg,200                      
4   |#ggg,300                      | |4   |#ggg,300                      
5   |                              | |5   |                              
6   |#gkkff,400,333333333333333333 | |6   |#gkkff,400                    
7   |                              | |7   |                              
8   |#key,200,300                  |o|8   |#key,200,300                  
    |                              | |9   |#fff,990                      
    |                              | |10  |                              
9   |#key,200,3012                 |x|11  |#key,200,301                  
    |                              | |12  |#gggg                         
    |                              | |13  |                              
10  |#key,200,302                  |o|14  |#key,200,302                  
11  |#gggg                         | |    |                              
12  |#ddd                          | |    |                              
13  |#key,200,303                  |o|15  |#key,200,303                  
14  |#ffff                         | |    |                              
15  |#key,200,3042                 |-|16  |#key,[SKIP]                   
16  |#ggg                          | |17  |                              
17  |                              | |    |                              
18  |                              | |    |                              
19  |                              | |    |                              
    |                              |x|18  |#key,200,304d                 
    |                              | |19  |                              
    |                              | |20  |                              
```

`#key` の行だけをチェックし、データが正しければ `o`、違っていれば `x` と表示されます。チェック対象外の行はブランクになります。

`[SKIP]` がある場合はチェックをスキップし、`-` と表示されます。

## 2. 使用方法

本プログラムはコンソールプログラムです。

実行形式は以下のとおりです。

```text
csvdiff チェック文字列 ファイル1 ファイル2 [-m ミスマッチ最大数] [-w 横の表示文字数] [-d] [-dbl_no_cut] [-integer]
```

### 引数・オプション

- **チェック文字列**  
  「1. ソフトの紹介」で説明した `#key` に相当する文字列を指定します。
- **ファイル1、ファイル2**  
  チェック対象となる2つのファイルを指定します。
- **`-m` オプション**  
  指定したミスマッチ数に達するとチェックを終了します。`0` を指定するとすべてチェックします。デフォルト値は `20` です。
- **`-w` オプション**  
  横方向の表示文字数を指定します。デフォルト値は `30` です。
- **`-d` オプション**  
  チェックの詳細を表示します。
- **`-dbl_no_cut` オプション**  
  ダブルクォーテーションを削除しません。
- **`-integer` オプション**  
  データを数値としてチェックします。

`-integer` オプションを指定すると、以下のように前ゼロがある場合でも、`0x` を付けた16進数を含めて数値としてチェックできます。

```text
19    |#key,0xc8,-500                |o|20    |#key,200,-000500              
20    |                              | |21    |                              
21    |#key,0000200,144              |o|22    |#key,200,0x000090             
22    |                              | |      |                              
```

### 実行例

```text
csvdiff #key aaa.csv bbb.csv
csvdiff #key aaa.csv bbb.csv -m 2
csvdiff #key aaa.csv bbb.csv -w 80
csvdiff #key aaa.csv bbb.csv -w 80 -m 0 -d
csvdiff -w 80 -m 0 -d #key aaa.csv bbb.csv
csvdiff -dbl_no_cut -w 80 -m 0 -d #key aaa.csv bbb.csv
csvdiff -integer #key aaa.csv bbb.csv
```
