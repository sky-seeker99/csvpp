# コメント削除プログラム その2

## 1. ソフトの紹介

本プログラムは、C/C++ソースのコメント（`// ～`、`/* ～ */`）を削除するコンソールプログラムです。

## 2. 使用方法

本プログラムはコンソールプログラムです。

### 実行形式

```text
c_cmt_del2 変換ファイル名 [-r 指定文字] [-buff buffer_size]
```

ファイル名はフルパスで指定してください。

ファイル名にはワイルドカードを使用できます。

### オプション

- `-r`：指定した文字列を含むコメントを削除しないようにします。
- `-buff`：1回の読み書きに使用するバッファサイズを指定します（単位：KByte）。
  通常は指定する必要はありませんが、ファイルが大きい場合などには、大きな値を指定すると有効です。
  指定しない場合は10KByteとなります。

### 使用例

```text
c_cmt_del2 c:\csv\*.cpp -r \
```

`-r` オプションは、コメントを削除しないための指定です。

```text
-r \
```

と指定した場合は、

```text
//\ ～
```

や

```text
/*\ ～ */
```

のコメントを削除しません。
