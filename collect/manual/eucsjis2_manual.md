# SJIS-EUC変換プログラム2

## 1. ソフトの紹介

本プログラムは、SJISコードとEUCコードを相互に変換するコンソールプログラムです。

ファイル名にはワイルドカードを使用できます。

## 2. 使用方法

本プログラムはコンソールプログラムです。

### 実行形式

```text
eucsjis2 sjis_euc|euc_sjis 変換前ファイル名 変換後ファイル名
```

ファイル名はフルパスで指定してください。

### 変換方法

- `sjis_euc`：SJISからEUCに変換します。このとき、改行コードは `0x0A` に変換します。
- `euc_sjis`：EUCからSJISに変換します。このとき、改行コードは `0x0D, 0x0A` に変換します。

### 改行コードを指定する場合

- `sjis_euc_win` / `euc_sjis_win`：改行コードを `0x0D, 0x0A` に変換します。
- `sjis_euc_unix` / `euc_sjis_unix`：改行コードを `0x0A` に変換します。

### 標準入力・標準出力

変換前ファイル名に `-` を指定すると、標準入力になります。

変換後ファイル名に `-` を指定すると、標準出力になります。

標準出力を使用する場合、改行コードは必ず `0x0D, 0x0A` になりますので注意してください。

### 使用例

```text
eucsjis2 sjis_euc c:\csv\in.txt c:\csv\out.txt
type c:\csv\in.txt | eucsjis2 euc_sjis - - > c:\csv\out.txt
```

## 3. 外字の変換

SJISコードの漢字で外字を使用する場合は、`eucsjis.exe` のあるディレクトリに `eucsjis.csv` ファイルを置きます。

`eucsjis.csv` には、変換規則を記述します。

添付の `eucsjis.csv` ファイルには、作者が調査したSJISコードからEUCコードへの変換規則が記述されています。

### フォーマット

```text
#sjis_euc,1文字目のコード,2文字目のコード上限,2文字目のコード下限,1文字目のコード差分,2文字目のコード差分
#euc_sjis,1文字目のコード,2文字目のコード上限,2文字目のコード下限,1文字目のコード差分,2文字目のコード差分
```

- `#sjis_euc`：SJISコードからEUCコードへの変換規則を指定します。
- `#euc_sjis`：EUCコードからSJISコードへの変換規則を指定します。

### 設定例

```text
#sjis_euc,250,73,64,2,177
#sjis_euc,250,83,74,-77,107
```
