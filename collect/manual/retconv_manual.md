# Excel用CSVファイル改行変換プログラム

（`0x0D 0x0A` → `0x0A`）

## 1. ソフトの紹介

本プログラムは、CSVMAKE2用のフィルタとして作られています。

単体でも動作します。

CSVファイル内の改行コードを、Excelで扱いやすい形式に変換します。

通常、データ内に改行があるCSVファイルをExcelで開くと、セル内に「・」が表示されることがあります。

これは、Excelのセル内改行コードが `0x0A (LF)` であるためです。

例えば、メモ帳で次のようなCSVファイルを作成したとします。

```text
a,b,"c
d"
```

改行コード（CR: `0x0D`、LF: `0x0A`）を表示すると、次のようになります。

```text
a,b,"c[CRLF]
d"
```

これをExcelで読み込むと、`c[CRLF]d` の部分が

```text
c・d
```

のように表示されます。

「・」が `0x0D` を表しています。

本プログラムは、この「・」の部分を削除します。

## 2. 使用方法

本プログラムはコンソールプログラムです。

### 実行形式

```text
retconv 変換前CSVファイル 変換後CSVファイル [-buff buffer_size]
```

### オプション

- `-buff`：1回の読み書きに使用するバッファサイズを指定します（単位：KByte）。通常は指定する必要はありませんが、ファイルが大きい場合などには、大きな値を指定すると有効です。指定しない場合は10KByteとなります。

### 使用例

```text
retconv c:\csv\bbb.csv c:\csv\ccc.csv
```

### CSVMAKE2でフィルタプログラムとして使用する場合

```text
csvmake2 d:\aaa.xls -x retconv c:\csv\bbb.csv c:\csv\ccc.csv
```
