# Excelファイル→CSVファイル変換プログラム拡張版

## 1. ソフトの紹介

指定したディレクトリ内にある**すべてのExcelファイルの全シート**を、CSV形式のファイルとして出力するソフトです。

CSVに変換するファイルが非常に多い場合などに便利です。

## 2. 使用方法

本プログラムはコンソールプログラムです。

### 実行形式

```text
csvmake3 Excelファイルのあるディレクトリ 出力先ディレクトリ [フィルタプログラム] [拡張子] [-tmp] [-proc] [-s シート名 シート名 …] [-S シート名 シート名 …]
```

### オプション

- `-s`  
  変換したいシート名を指定します。ワイルドカードが使用できます。

- `-S`  
  変換したくないシート名を指定します。ワイルドカードが使用できます。

- `-tmp`  
  CSVファイルをいったんテンポラリファイルに出力してから、元のCSVファイルにコピーします。

- `-proc`  
  `csvmake3` 実行後、Excelのプロセスが残っていないかチェックし、残っていた場合は削除します。

### 使用例

```text
csvmake3 c:\xls_dir c:\csv
csvmake3 c:\xls_dir c:\csv csvtab txt
csvmake3 c:\xls_dir c:\csv -s aaa bbb sheet* -S sheet_x*
csvmake3 c:\xls_dir c:\csv csvtab txt -s aaa bbb sheet* -S sheet_x*
```

## 3. フィルタプログラムについて

フィルタプログラムは、CSVファイルへの変換後に実行されるファイル変換プログラムです。

フィルタプログラム（またはバッチファイル）を自分で作成する場合は、以下の引数を使用してください。

1. **第1引数**：変換前CSVファイル
2. **第2引数**：変換後ファイル
3. **第3引数**：シーケンス番号（三桁、前ゼロ付き）
4. **第4引数**：出力先ディレクトリ名
5. **第5引数**：シート名

## 4. 賢い使用方法

`c:\csv` ディレクトリに出力したい場合は、以下のバッチファイルを作成します。

### バッチファイルの中身

```bat
csvmake3 %1 c:\csv
```

このファイルを作成したら、このバッチファイルに対して、Excelファイルが入っているディレクトリをドラッグ＆ドロップします。

すると、プログラムが起動してCSVファイルを作成します。
