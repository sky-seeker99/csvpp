# テキストファイル連結・分割プログラム

## 1. ソフトの紹介

本プログラムは、テキストファイルの連結や一部の切り出しなどを行うコンソールプログラムです。

## 2. 使用方法

本プログラムはコンソールプログラムです。

実行形式は以下のとおりです。

```text
txt_catcut in_file out_file [-new] [-r_offset offset] [-w_offset offset] [-size size] [-buff buffer_size]
```

### オプション

オプションを何も指定しない場合は、`out_file` の後に `in_file` の内容が付加されます。

| オプション | 説明 |
|---|---|
| `-new` | 新規作成します。 |
| `-r_offset` | 入力ファイルのオフセットライン数を指定します。指定しない場合は、先頭から読み出します。 |
| `-w_offset` | 出力ファイルのオフセットライン数を指定します。指定しない場合は、ファイルの最後から付加されます。 |
| `-size` | 読み書きするサイズを指定します。指定しない場合は、入力ファイルの全ライン数から入力ファイルのオフセットライン数を引いた値になります。 |
| `-buff` | 1回の読み書きに使用するサイズを指定します（単位：KByte）。通常は指定する必要はありませんが、ファイルが大きい場合などには、大きな値を指定すると有効です。指定しない場合は10KByteです。 |

### 注意事項

- オフセットライン数は、一番初めの行を **1** として数えます。
- 数字には16進数を使用できます。16進数を指定する場合は、先頭に `0x` を付けます。  
  例：`0x1000`、`0xa0df`

## 3. 使用例

### ファイルを連結する場合

以下の例では、`in1.txt`、`in2.txt`、`in3.txt` の内容を順番に `out.txt` へ連結します。

```text
txt_catcut in1.txt out.txt -new
txt_catcut in2.txt out.txt
txt_catcut in3.txt out.txt
```

### 100バイト単位に分割する場合

以下の例では、入力ファイルを100バイト単位に分割します。

```text
txt_catcut in.txt out1.txt -new -size 100
txt_catcut in.txt out2.txt -new -size 100 -r_offset 101
txt_catcut in.txt out3.txt -new -size 100 -r_offset 201
```
