# CSVファイル文字列属性変換プログラム

## 1. ソフトの紹介

本プログラムは、CSVMAKE2用のフィルタとして作られています。

単体でも動作します。

CSVファイルをExcelで開く際に、数値を文字列として扱えるように変換します。

## 2. 使用方法

本プログラムはコンソールプログラムです。

### 実行形式

```text
csvstrcnv [+all] [+num] [+numex] [+dbl] [+single] CSV入力ファイル CSV出力ファイル [-buff buffer_size]
```

### オプション

- `-buff`：1回の読み書きに使用するバッファサイズを指定します（単位：KByte）。通常は指定する必要はありませんが、ファイルが大きい場合などには、大きな値を指定すると有効です。指定しない場合は10KByteとなります。
- `+all`：すべてのデータを文字属性に変換します。
- `+num`：数値のみを文字属性に変換します。
- `+numex`：数値、`/`、`:` のみを文字属性に変換します。
- `+dbl`：ダブルクォーテーションで囲まれたデータのみを文字属性に変換します。
- `+single`：シングルクォーテーションで囲まれたデータのみを文字属性に変換します。

### 使用例

```text
csvstrcnv +all c:\csv\bbb.csv c:\csv\ccc.csv
```

### CSVMAKE2でフィルタプログラムとして使用する場合

```text
csvmake2 d:\aaa.xls -x "csvstrcnv +all" c:\csv\bbb.csv c:\csv\ccc.csv
```
